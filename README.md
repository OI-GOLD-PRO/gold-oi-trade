# OI Gold Pro Trade

แอปเทรดทองที่ต่อยอดจาก OI Gold Pro: กดเทรดจากมือถือ → ส่งคำสั่งเข้า MT5 บนคอม

```
มือถือ (แอป) ⇄ Hub บน Cloudflare (ฟรี) ⇄ EA สะพานใน MT5 บนคอม
```

| โฟลเดอร์ | คืออะไร |
|---|---|
| `hub/` | ตัวกลางบน Cloudflare Worker — รับสถานะจาก EA, ส่งคำสั่งจากแอป, มีหน้าทดสอบในตัว |
| `ea/OI_Trade_Bridge.mq5` | EA สะพาน — ส่งราคา/บัญชี/ออเดอร์ขึ้น hub และทำตามคำสั่ง |
| `icon/` | ไอคอนหน้าจอโฮม (ลูกศรเขียวขึ้น–แดงลงไขว้กัน, OI สีทองตรงกลาง) |
| `index.html`, `trade.js`, `trade.css` | แอปเทรด (กราฟ + OI จาก OI Gold Pro, ตั๋วออเดอร์, ลากเส้น TP/SL) |
| `tools/` | สคริปต์ทดสอบ hub, ทดสอบแอป และสร้างไอคอน |

เวอร์ชัน: **v0.3.00** (เฟส 2 – แอปเทรด, ฐาน OI Gold Pro V1.7.00)

แอป: **https://oi-gold-pro.github.io/gold-oi-trade/**

## ติดตั้งเฟส 1 (ทำบนคอมที่เปิด MT5)

### 1. Hub บน Cloudflare
1. สมัคร Cloudflare ฟรีที่ dash.cloudflare.com
2. ติดตั้ง Node.js (LTS) จาก nodejs.org
3. เปิด Command Prompt ในโฟลเดอร์ `hub` แล้วพิมพ์ทีละบรรทัด:
   ```
   npm install
   npx wrangler login
   npx wrangler deploy
   ```
   จะได้ลิงก์แบบ `https://oi-trade-hub.<ชื่อคุณ>.workers.dev` — จดไว้
4. สร้างรหัสลับ 2 ชุด (รันคำสั่งนี้ 2 ครั้ง ได้รหัสคนละชุด):
   ```
   node -e "console.log(crypto.randomUUID())"
   ```
5. ใส่รหัสเข้า hub:
   ```
   npx wrangler secret put APP_KEY      ← วางรหัสชุดที่ 1 (ใช้ในแอป/หน้าทดสอบ)
   npx wrangler secret put EA_KEY       ← วางรหัสชุดที่ 2 (ใช้ใน EA)
   ```

### 2. EA ใน MT5 (ใช้บัญชีเดโมก่อน)
1. MT5 → File → Open Data Folder → `MQL5/Experts` → วาง `OI_Trade_Bridge.mq5`
2. เปิดใน MetaEditor แล้วกด **F7** (Compile)
3. MT5 → Tools → Options → Expert Advisors → ติ๊ก **Allow WebRequest for listed URL** แล้วเพิ่มลิงก์ hub
4. ลาก EA ใส่กราฟ XAUUSD ใส่ค่า:
   - `HubURL` = ลิงก์ hub (ไม่มี / ท้าย)
   - `EAKey` = รหัสชุดที่ 2
   - `MaxLots` = เพดานล็อตต่อออเดอร์ (เริ่มต้น 0.10)
5. เปิดปุ่ม **Algo Trading** — มุมซ้ายบนกราฟต้องขึ้น `online`

### 3. ทดสอบจากมือถือ
เปิดลิงก์ hub ในมือถือ → ใส่รหัสชุดที่ 1 → ต้องเห็นจุดเขียว "EA ออนไลน์" กับยอดบัญชี
ลองกด BUY 0.01 บนเดโม แล้วกดปิด

## ระบบกันพลาด
- คำสั่งที่ EA ไม่ได้รับภายใน 10 วิ → ยกเลิกทิ้ง ไม่ยิงย้อนหลัง
- EA ไม่ทำคำสั่งที่อายุเกิน `MaxCmdAgeMs` (8 วิ) และไม่ทำคำสั่งซ้ำ
- ล็อตเกิน `MaxLots` → ปฏิเสธ
- EA ออฟไลน์ → hub ไม่รับคำสั่ง
- รหัสแอปกับรหัส EA แยกกัน ใช้แทนกันไม่ได้
- ตั้ง `ManageAllOnSym = false` ถ้าอยากให้แอปแตะเฉพาะออเดอร์ที่เปิดจากแอป

## โควตาฟรีของ Cloudflare
ฟรี 100,000 request/วัน — EA ซิงก์ทุก 1 วิเฉพาะตอนเปิดแอปดู, ตอนไม่มีคนดูซิงก์ทุก 5 วิ
ใช้คนเดียวอยู่ราว 30–50k/วัน

## เฟส 2 – แอปเทรด

### อัปเดต hub (ทำครั้งเดียว)
ในโฟลเดอร์ `hub` บนคอม (โหลดโค้ดใหม่จาก GitHub ก่อน):
```
npx wrangler deploy
npx wrangler secret put OI_CODE        ← รหัสเข้า OI Gold Pro ของคุณ (hub ใช้อ่านข้อมูล OI อย่างเดียว)
```
ไม่บังคับ — รหัสเข้าแอปเทรดแบบสั้นสำหรับพิมพ์บนมือถือ:
```
npx wrangler secret put TRADE_USERS
[{"code":"ตั้งเอง","name":"ชื่อ","expire":"9999-12-31"}]
```
รหัส APP_KEY ใช้เข้าแอปได้เสมอ

### การใช้งาน
- กราฟเป็น **ราคาโบรกจริง** (เลื่อนตามราคาจาก EA) เส้น OI แปลงจาก GC มาเป็นราคาโบรกให้แล้ว ชิป "GC−โบรก" คือส่วนต่าง
- ปัดแกนราคาขวาไปทางซ้าย = แกนราคา GC
- แตะ **SL / TP** = เปิด/ปิดเส้น, กดค้าง = พิมพ์ราคาเอง แล้ว **ลากเส้นบนกราฟ** — โชว์กำไร/ขาดทุน (สกุลเงินบัญชี) และ R:R ทันที
- 🧲 ดูดเส้นเข้า OI wall / Max Pain เมื่อลากเข้าใกล้
- ปุ่ม **SELL / BUY** ล่างสุด = ส่งออเดอร์ราคาตลาดทันที (มีหน้าต่างยืนยัน)
- **ตั้งราคา SELL / BUY** = Pending: กดครั้งแรกโชว์เส้น ENTRY ให้ลาก กดอีกครั้งเพื่อส่ง แอปเลือก LIMIT / STOP ให้เองตามตำแหน่ง (✕ = ยกเลิก)
- **เสี่ยง %** = คำนวณล็อตจาก Equity × % ÷ ระยะ SL
- ปุ่ม **ออเดอร์** = แดชบอร์ดบัญชี + ไม้ที่เปิด (แก้ SL/TP, ปิด, ปิดทั้งหมด) + Pending (แก้, ยกเลิก)
- ทุกคำสั่งมีหน้าต่างยืนยันก่อนส่ง

ทดสอบแอปในเครื่อง: `python3 tools/test-app.py <lightweight-charts.js> <โฟลเดอร์รูป>`

## รหัสเข้าแอปใน Google Sheet ("OI Trade Users")
ชีตแยกต่างหาก (ไม่ใช่ชีต OI Gold Pro) ชีตเป็นส่วนตัว hub อ่านผ่าน Apps Script ที่ต้องใช้รหัสลับ
- แท็บ `trade_users`: **code | name | expire** (yyyy-mm-dd, เว้นว่าง = ไม่จำกัด) เพิ่มแถว = เพิ่มคน, เปลี่ยน expire เป็นวันในอดีต = ปิดสิทธิ์ (มีผลภายใน 1 นาที)
- สคริปต์: `sheet/users-apps-script.gs`
- hub secrets: `USERS_URL` (ลิงก์ web app), `USERS_SECRET` (SECRET ในสคริปต์)
- APP_KEY ของเจ้าของเข้าได้เสมอ แม้ชีตล่ม

hub deploy อัตโนมัติจาก GitHub Actions ทุกครั้งที่แก้โฟลเดอร์ `hub/`

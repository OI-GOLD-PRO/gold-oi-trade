## 1. ภาพรวม

**OI Gold Pro Mini** คือจอตั้งโต๊ะ ESP32 (CYD 2.8") ที่แสดงกราฟราคาทอง GC1 แบบสด พร้อมข้อมูล Open Interest ของออปชันทองสัญญาวันนี้ ในหน้าตาเดียวกับเว็บแอป **OI Gold Pro** (repo `OI-GOLD-PRO/gold-oi-pro`)

แสดงอะไรบ้าง
- ราคา GC1 สด (ทุก 1 วินาที) + เปลี่ยนจากราคาเปิดวัน + Expected Move
- กราฟแท่งเทียน 1m / 5m / 15m / 1h ซูม −/+ ลากเลื่อนดูย้อนหลัง/ขึ้นลงได้
- OI ราย strike: แท่ง Call (เขียว, แนวต้าน) และ Put (แดง, แนวรับ) ยื่นจากขอบขวา, Volume วันนี้ (ฟ้า/ส้ม) จากขอบซ้าย
- โซนกำแพง OI 10 อันดับต่อฝั่ง (1–5 กว้าง ±2.5 + เส้นทึบ, 6–10 กว้าง ±1.25), Volume 5 อันดับเป็นเส้นทอง
- เส้น gmf itd (ฟ้า), gmf M (ส้ม), Max Pain (บานเย็น), EM± (เทา)
- แจ้งเตือนเข้าโซน / ทะลุโซน ด้วยแถบสี + ไฟ LED + เสียง
- ตั้ง WiFi จากจอ, หมุนจอ 4 ทิศ, ความสว่าง, ปิดจอ / ปิดเองตามเวลา, อัปเดตเฟิร์มแวร์ผ่าน WiFi

ผู้ใช้หลัก: เจ้าของโปรเจกต์ใช้เอง ในอนาคตอาจขาย/แจกให้คนอื่น (ยังไม่มีระบบล็อกอิน ดูหัวข้อ 10)

## 3. ฮาร์ดแวร์

**บอร์ด:** `ESP32-2432S028` รุ่น **2 USB** (micro-USB + USB-C) จอ 2.8" 240×320 สัมผัสแบบกด (resistive, XPT2046)
ชิป: ESP32-WROOM-32 (ESP32 ธรรมดา ไม่ใช่ S3) · Flash 4MB · ไม่มี PSRAM

> ⚠️ **ชิปจอเป็น ILI9341 ไม่ใช่ ST7789** (บอร์ด 2 USB หลายล็อตเขียนว่า ST7789 แต่ล็อตนี้เป็น ILI9341 — ถ้าใช้ ST7789 จอจะขาวทั้งจอ)
> `invert = false`, `rgb_order = false`, `freq_write = 27MHz`

| อุปกรณ์ | พิน |
|---|---|
| จอ (SPI2/HSPI) | SCLK 14, MOSI 13, MISO 12, DC 2, CS 15, RST −1, BL 21 (PWM) |
| สัมผัส XPT2046 (SPI3/VSPI แยกบัส) | CLK 25, MOSI 32, MISO 39, CS 33, IRQ 36 |
| LED RGB (active LOW) | R 4, G 16, B 17 |
| ลำโพง (ช่อง SPEAK, ผ่านแอมป์ในบอร์ด) | DAC IO26 |
| เซ็นเซอร์แสง (LDR หน้าจอ) | IO34 |
| วัดแบต (ยังไม่มีวงจร — ต้องต่อตัวแบ่งแรงดัน 1:2 เอง) | IO35 (ช่อง P3) |
| ปุ่ม | BOOT (IO0), RST |

**ค่าคาลิเบรตสัมผัส** (วัดจากบอร์ดผู้ใช้ 2026-10-28, ใช้กับ `lcd.setTouchCalibrate`):
```
{291, 3625, 281, 205, 3806, 3629, 3834, 192}
```
บอร์ดเครื่องอื่นอาจต่างเล็กน้อย — ถ้าจะทำหลายเครื่อง ควรเพิ่มหน้าคาลิเบรตในเมนู (`lcd.calibrateTouch`) แล้วเก็บใน Preferences

**ไฟเลี้ยง:** USB-C/micro-USB 5V · ถ้าจะใช้แบต แนะนำโมดูลชาร์จ+บูสต์ 5V (เช่น IP5306) เข้า VIN — ห้ามต่อ LiFePO4 เข้าตรง (แรงดันหลัง LDO ต่ำเกิน)

**ลำโพง:** 8Ω 0.5–2W หัว MX1.25 2 ขา (ช่อง SPEAK) · ใช้แค่ `tone()` เสียงบี๊บ

## 5. การไหลของข้อมูล

```
TradingView (scanner + quote/chart websocket, ช้า ~10 นาทีสำหรับออปชัน)
        │  cron ทุก 2 นาที
        ▼
Cloudflare Worker gc-yahoo  ── Durable Object "OptState" (สัญญาวันนี้: OI, IV, greeks, volume, gmf itd/M, EM)
        │
        │  GET /mini?tf=1|5|15|60   (แคช 15 วินาที, รวมแท่ง Gold.F BlackBull + offset)
        ▼
ESP32 ดึงทุก 15 วินาที ─────────────┐
                                     ├─► ราคาสด = Bybit lastPrice + off
Bybit REST ทุก 1 วินาที (งานเน็ตแกน 0) ┘     (อัปเดตแท่งปัจจุบัน + เปิดแท่งใหม่เองตามเวลา NTP)
  https://api.bybit.com/v5/market/tickers?category=linear&symbol=XAUUSDT  (เชื่อมต่อค้างไว้ · ปิดก่อนดึง /mini ถ้าหน่วยความจำเหลือน้อย)
  หมายเหตุ: v0.5.0 ลอง WebSocket แล้วบนบอร์ดจริงกราฟไม่ขึ้น → เอาออกใน v0.5.2
```

- **ราคาที่แสดง** = `livePrice()` → ถ้า Bybit สด (ข้อความล่าสุด <6 วินาที) และมี `off` ใช้ `perp + off`, ไม่งั้นใช้ `p` จาก Worker
- **offset** = median ของ (Gold.F close − Bybit close) 5 แท่ง 1 นาทีล่าสุดที่ปิดแล้ว (ฟังก์ชัน `liveOffset` ใน Worker) — วิธีเดียวกับแอป
- ตลาด GC ปิด (`mkt` false, ส. 05:00 – จ. 05:00 ไทย): ไม่ดึง/ไม่ใช้ราคา Bybit (Bybit ยังซื้อขายแต่ offset ค้าง) → แสดงราคาปิด Gold.F
- หน่วยความจำวัดจริง (v0.5.2, หลังเชื่อม WiFi + เปิดหน้าเมนู): ว่าง 113KB, ก้อนใหญ่สุด 71KB — ดูได้จากบรรทัดเล็กหัวเมนู `d<miniErr> <px|--|cls> <ว่าง>/<ก้อนใหญ่สุด>k`
- จุดสถานะในแถบหัว: เขียว = ราคาสด, ทอง = ใช้ข้อมูล Worker (ไม่สด), แดง = ไม่มีข้อมูล/เกิน 60 วินาที
- เวลา: NTP `pool.ntp.org` เวลาไทย UTC+7 (`configTime(7*3600, 0, …)`)

## 6. API `/mini` (v2)

`GET https://gc-yahoo.oigoldpro.workers.dev/mini?tf=1|5|15|60` (ค่าเริ่ม `1`) · CORS เปิด · แคช 15 วินาทีต่อ tf · ขนาด ~1.3–3 KB

| ฟิลด์ | ชนิด | ความหมาย |
|---|---|---|
| `v` | int | เวอร์ชันสคีมา (ตอนนี้ 2) |
| `now` | sec | เวลาเซิร์ฟเวอร์ |
| `p`, `pt` | float, sec | ราคาปิดแท่งล่าสุด Gold.F และเวลาแท่ง |
| `bs` | sec | วินาทีต่อแท่ง (60/300/900/3600) |
| `bt`, `lt` | sec | เวลาแท่งแรก / แท่งล่าสุดใน `b` |
| `b` | `[[o,h,l,c],…]` | แท่งเทียน Gold.F สูงสุด 120 แท่ง เก่า→ใหม่ |
| `off` | float\|null | offset ให้บวกกับราคา Bybit |
| `c`, `ct` | — | ราคาปิด 40 แท่ง 1m (เก็บไว้ให้เฟิร์มแวร์ v0.1 — เลิกใช้แล้ว) |
| `F` | float | ราคา GC1 ที่ใช้คำนวณออปชัน |
| `open`, `em` | float | ราคาเปิดวันเทรด / Expected Move (straddle ATM ตอนเปิดวัน) |
| `itd`, `gm`, `mp` | float | gmf itd / gmf M / Max Pain |
| `cw`, `pw` | float | Call Wall / Put Wall (gamma×OI สูงสุด) |
| `exp`, `root` | str | เวลาหมดอายุ (ไทย "MM-DD HH:MM") / รหัสสัญญา |
| `upd` | sec | เวลา Worker poll ล่าสุด |
| `mkt` | bool | ตลาดเปิดอยู่ไหม |
| `s` | `[[k, callOI, putOI, volC, volP, rankC, rankP, topVol, ivOTM%×10 (คำนวณเอง)],…]` | ราย strike ภายใน ±$80 จากราคา · rank 0 = ไม่ติด 10 อันดับ · topVol 1 = Volume 5 อันดับแรก |
| `z` | `[[k, lo, hi, 'C'\|'P'\|'V', callOI, putOI],…]` | โซนแจ้งเตือน ≤12 โซนใกล้ราคา (กติกาเดียวกับ Telegram ของแอป) |
| `nx` | `[[วินาที UTC, ชื่อข่าว ≤28 ตัว ASCII],…]` | ข่าวแดง USD (impact H) 3 รายการถัดไปภายใน 24 ชม. จาก `gold-oi-pro/news.json` (แคช 10 นาที) · v0.6 |
| `iv` | float | ATM IV % คำนวณเอง Black-76 (`smileIV` แบบ live.js) · v0.7.2 |
| `sm` | `[F, a, b, c]` | เส้นโค้ง IV: iv% = a + b·(k−F) + c·(k−F)² (fit ±4% รอบ F จาก put-call parity) · v0.7.2 |
| `os`, `vs` | `[ค่ากลาง, SD]` | การกระจายของ OI / Volume ราย strike (ถ่วงน้ำหนัก) · v0.7.2 |
| `sd` | float | SD ของ OI ($) — **ผู้ใช้กำหนด: SD = ส่วนเบี่ยงเบนมาตรฐานของ OI ไม่ใช่จาก IV** · v0.7.2 |
| `dl` | `[คะแนน, 'A'\|'C'\|'N']` | Dealer รับ/ไล่/กลาง (`dealerScore`: gamma เทียบ flip 0.4 + แรงตรึง 0.25 × vol/OI ±$10) · v0.7.1 |

**ต้องมี `code=` (v0.7)** = รหัสเข้าแอป OI Gold Pro · Worker ตรวจกับ Apps Script `?api=login` (ชีตเดียวกับแอป) แคชผล 10 นาที (ไม่ผ่าน 2 นาที) · ไม่ผ่าน → 401 `{error:'auth', reason}` · Apps Script ล่ม → 503

### Endpoint อื่นของ Mini (v0.6, ใน `gcw/src/index.js` + `gcw/src/flash.js`)
| Endpoint | ใช้ทำอะไร |
|---|---|
| `GET /mini/login?code=` | จอตรวจรหัสตอนผู้ใช้พิมพ์ → `{ok, reason: invalid\|expired\|server, exp, code}` (ลองตัวพิมพ์ใหญ่/เล็กแบบแอป · `code` = แบบที่ใช้ได้จริง) |
| `GET /mini/dash?code=` | ผลวิเคราะห์ ds แบบตัวเลข `{u, tr, sc, g, lv:[[p,'R'\|'S'\|'P',ความแข็ง1-3]]}` · Worker อ่าน Apps Script `?api=data&sym=gold&code=<DASH_CODE หรือรหัสของจอ>` · แคช 5 นาที |
| `GET /mini/flash` | หน้าเว็บติดตั้งเฟิร์มแวร์ (ESP Web Tools) · manifest `/mini/flash/manifest.json` ชี้ `mini/dist/factory.bin` |

**Cloudflare secrets ของ Worker `gc-yahoo`** (ตั้งที่ Workers → gc-yahoo → Settings → Variables and Secrets · `keep_vars = true` จะไม่ลบตอน deploy):
- `DASH_CODE` — (ไม่จำเป็นตั้งแต่ 2026-11-02) ถ้าไม่ตั้ง /mini/dash ใช้รหัสแอปของจอที่ส่งมาอ่านชีต
- (v0.6 เคยมี `MINI_ADMIN` / `MINI_AUTH` + หน้า /mini/admin + รหัส GX — **เอาออกใน v0.7** ใช้รหัสแอปแทน)

ฟังก์ชันใน `gcw/src/index.js`: `miniPayload()`, `strikeTable()`, `maxPain()`, ตัว route `if (url.pathname === '/mini')`
**ถ้าเพิ่ม/เปลี่ยนฟิลด์:** เพิ่มเท่านั้น อย่าลบ/เปลี่ยนความหมายฟิลด์เดิม (เครื่องที่ยังไม่อัปเดตยังใช้อยู่) · ถ้าจำเป็นต้องเปลี่ยน ให้เพิ่ม `v` แล้วรองรับทั้งสองแบบ · อัปเดตเทสต์ใน `gcw/test.mjs`

## 7. สถาปัตยกรรมเฟิร์มแวร์ (`OIGoldProMini.ino`)

ไลบรารี: **LovyanGFX** (จอ+สัมผัส, sprite: กราฟ 8-bit, แถบสถานะ 8-bit · แถบหัววาดเฉพาะส่วนที่เปลี่ยนด้วย text padding → ไม่กระพริบ), **ArduinoJson v7**, ESP32 core: WiFi, WiFiClientSecure (`setInsecure()`), HTTPClient, HTTPUpdate, Preferences, FreeRTOS

### สองแกน (ตั้งแต่ v0.5.0)
- **แกน 0 — `netTask`** (stack 12KB): ราคา Bybit REST ทุก 1 วินาที, ดึง `/mini` (`fetchMini` → แปลงลง `NT` → ล็อก `mx` → คัดลอกไป `ND`, `ndReady = true`), เช็กอัปเดต (`reqUpd` → `updRes`)
- **แกน 1 — `loop()`**: สัมผัส, วาด, แจ้งเตือน, LED/เสียง · `applyNet()` รับ `ND` → `D` (ทิ้งถ้า `ND.tf != tfIdx`), ดู `perpSeq` ว่าราคาเปลี่ยนไหม แล้วตั้งธง `dirty*`
- **ห้ามวาดจอ/อ่านสัมผัสจาก `netTask`** และ **ห้ามแก้ `D` จาก `netTask`** (D เป็นของแกน 1)
- ตั้ง WiFi และ OTA ต้อง `pauseNet(true)` ก่อน (หยุดงานเน็ต + ปิดการเชื่อมต่อ) แล้ว `pauseNet(false)` หลังเสร็จ
- ธงสื่อสาร (volatile): `reqFetch` (ขอดึงทันที เช่น เปลี่ยน TF/ปุ่มรีเฟรช), `reqUpd`, `updRes`, `netPause`, `netIdle`, `ndReady`

### หน้าจอ (`enum Screen`)
`SC_MAIN` กราฟ · `SC_MENU` เมนู · `SC_WIFI` รายการ WiFi · `SC_KB` คีย์บอร์ด (`kbFor` 0 = รหัส WiFi, 1 = รหัสเข้าใช้: `openCode` / `submitCode` → งานเน็ต `doLogin` → `loginResult`) · `SC_DASH` Dashboard 3 หน้า (แตะแถบหัว/เมนู · ปุ่มล่าง CLOSE / < PREV / NEXT > · หน้า 1 สรุป ds + Dealer + IV/SD, หน้า 2 OI ราย strike เต็มจอ + เส้นโค้ง IV + แถบ ±1/±2 SD ของ OI, หน้า 3 Volume ราย strike + SD ของ Volume) · `SC_SND` ตั้งเสียงแจ้งเตือน (เมนู → ALERT SOUNDS)

ท่าทางบนหน้ากราฟ (v0.6.1): แตะปุ่มล่าง · ลาก = เลื่อนกราฟ (ลากซ้ายได้ เว้นที่ว่างขวา) · **เส้นเล็ง = ไอคอน ⊕ บนแถบล่าง (v0.7.6) กดเปิด/ปิด** (เปิดอยู่ แตะ/ลาก = ย้ายเส้นเล็ง · AUTO เว้นขวา ~15%, ลากชิดขวาได้ v0.7.5 · `overlayCross`: ราคา, เวลา/OHLC แท่ง, OI strike ใกล้สุด) · แตะแกนราคาหรือป้าย AUTO = กลับอัตโนมัติ · **แตะแถบหัว = Dashboard** · แตะแถบแจ้งเตือน = ปิด

### ลูปหลัก `loop()` แกน 1 (ทุก ~2 ms)
| งาน | ความถี่ | ฟังก์ชัน |
|---|---|---|
| รับข้อมูลจากงานเน็ต + แท่งปัจจุบัน + แจ้งเตือน | ทุกลูป (ทำงานจริงเมื่อมีข้อมูลใหม่/ราคาเปลี่ยน/ทุก 1 s) | `applyNet()` → `tickCandle()` → `evalAlerts()` |
| เปิด/ปิดจอตามสถานะ | 500 ms | `updateScreenPower()` |
| ไฟ LED กะพริบ / เสียงบี๊บ / หมดเวลาแถบแจ้งเตือน | ทุกลูป | `serviceAlerts()` |
| สัมผัส (แตะ/ลาก) | ทุกลูป | `handleTouchMain()` → `handleMainTap()` |
| วาดกราฟ/แถบสถานะ | เมื่อ `dirtyChart/dirtyStatus` · ห่างกัน ≥150 ms | `drawChart()`, `drawStatus()` |
| แถบหัว | เมื่อราคาเปลี่ยน (≥150 ms) + ทุก 1 s (เวลา/WiFi/แบต) | `drawHeader()` |

### งานเน็ต `netTask` แกน 0
| งาน | ความถี่ |
|---|---|
| ราคา Bybit (REST) | ทุก 1 s |
| ดึง `/mini` | 15 s (`FETCH_MS`) หรือทันทีเมื่อ `reqFetch` · ล้มเหลว → ลองใหม่ทุก 5 s |
| เช็กเวอร์ชันใหม่ | หลังเปิดเครื่อง 20 s + ทุก 6 ชม. หรือเมื่อ `reqUpd` |

ระหว่างนิ้วกดค้าง (`tDown`) loop ไม่วาดอัตโนมัติ (`handleTouchMain` วาดเองทุก 60 ms) · ตอนจอดับ งานเน็ตยังทำงาน และ `applyNet()` ยังเช็กแจ้งเตือน แต่ไม่วาด

## 8. Build / ติดตั้ง / ออกเวอร์ชัน

### ผู้ใช้ติดตั้งครั้งแรก (USB)
Arduino IDE 2.x · Board: **esp32 by Espressif** → **ESP32 Dev Module** · Partition Scheme: **Minimal SPIFFS (1.9MB APP with OTA)** (สำคัญ — ไม่งั้นไม่มีที่ OTA) · Libraries: **LovyanGFX**, **ArduinoJson** · เปิด `mini/OIGoldProMini/OIGoldProMini.ino` (ต้องมี `logo.h` ในโฟลเดอร์เดียวกัน) → Upload · ถ้าค้าง "Connecting…" กด BOOT ค้าง

### CI (GitHub Actions)
- push ที่แตะ `mini/**` → `build-mini-firmware.yml`: PlatformIO (`espressif32@6.9.0`, `min_spiffs.csv`) คอมไพล์ → สร้าง `dist/firmware.bin`, `dist/factory.bin`, `dist/version.json` (อ่านเลขจาก `#define FW_VER`) → bot commit `"Mini firmware build [skip ci]"`
- push ที่แตะ `gcw/**` → `deploy-gcw.yml`: `node gcw/test.mjs` แล้ว `wrangler deploy` (ต้องผ่านเทสต์)
- ขนาดเฟิร์มแวร์ตอนนี้ ~1.09 MB จากที่ว่าง 1.9 MB

### ออกเวอร์ชันใหม่ให้เครื่องผู้ใช้ (OTA)
1. แก้โค้ดใน `mini/OIGoldProMini/`
2. **เพิ่มเลข `#define FW_VER`** (เช่น 0.4.1 → 0.4.2) — ถ้าไม่เพิ่ม เครื่องจะไม่เห็นว่ามีอัปเดต
3. จดใน `CHANGELOG.md` (commit เดียวกัน)
4. push `main` → รอ CI เขียว → `mini/dist/version.json` ต้องเป็นเลขใหม่
5. ผู้ใช้กด MENU → CHECK FOR UPDATE → UPDATE
6. ถ้า CI แดง: dist ไม่เปลี่ยน เครื่องผู้ใช้ไม่ได้รับของเสีย — แก้แล้ว push ใหม่

> ⚠️ ถ้าเปลี่ยน partition scheme, ชื่อไฟล์ใน dist, หรือ URL OTA จะทำให้เครื่องเดิมอัปเดตไม่ได้ ต้องให้ผู้ใช้เสียบ USB ใหม่ — หลีกเลี่ยง

## 9. ข้อตกลงและสิ่งที่ห้ามทำ

1. **Worker `gcw/` ใช้ร่วมกับแอป OI Gold Pro และการแจ้งเตือน Telegram/Web Push** — ห้ามแก้ `/opt`, `/px`, `/gf`, `/levels`, `/push/*`, `/tg/*`, cron หรือ Durable Object โดยไม่จำเป็น · ถ้าต้องแก้ ให้ระบุใน CHANGELOG ช่อง "ระวัง"
2. ห้ามใส่ secret/token ในโค้ด · `wrangler.toml` ต้องคง `keep_vars = true`
3. ห้ามแก้ไฟล์ใน `mini/dist/` ด้วยมือ
4. สีและคำศัพท์ต้องตรงแอป: Call = เขียว = แนวต้าน, Put = แดง = แนวรับ, ชื่อ "gmf itd" (สัญญาวันนี้) และ "gmf M" (ทุกสัญญา ≤30 วัน), Max Pain บานเย็น
5. ข้อความบนจอเป็นภาษาอังกฤษ (ฟอนต์ในตัวไม่มีไทย) · คอมเมนต์ในโค้ดเป็นภาษาไทยได้ (สไตล์เดิมของ repo)
6. หน่วยความจำ: ESP32 ไม่มี PSRAM — sprite กราฟ 8-bit ≈ 55–61KB + แถบสถานะ ≈ 5KB + stack งานเน็ต 12KB และการเชื่อมต่อ TLS ~40KB ต่อทาง (บทเรียน v0.5.0: TLS 2 ทาง + sprite แถบหัว 16-bit + WebSocket = หน่วยความจำไม่พอ กราฟไม่ขึ้น) — ระวังเพิ่ม buffer ใหญ่ / JSON ใหญ่ (`/mini` ควร < 8 KB) · `doUpdate()` หยุดงานเน็ตและลบ sprite ทั้งหมดก่อนดาวน์โหลด
7. อย่าใช้ `delay()` ยาวในลูปหลัก (สัมผัส/LED/เสียงจะค้าง)
8. ค่าคาลิเบรตสัมผัส และ `Panel_ILI9341` อย่าเปลี่ยนโดยไม่ได้ทดสอบบนบอร์ดจริง
9. ก่อนตอบผู้ใช้ว่า "เสร็จ" ให้ดูว่า CI build ผ่าน
10. **ผู้ใช้ต้องการให้ถามก่อนสร้าง/แก้เมื่อเขาแค่เสนอหรือถามไอเดีย** — ถ้าเขาสั่งชัด ("ได้เลย", "ทำเลย") ค่อยลงมือ

### Mini v0.4.2 — 2026-10-30 — ChatGPT

- ถ้าแก้ Worker ใช้หัว `### Worker gc-yahoo — วันที่ — ผู้แก้`
- ถ้าแก้ไฟล์นี้ (HANDOFF.md) ให้อัปเดตหัวข้อที่เกี่ยวข้องด้วย ไม่ใช่แค่ CHANGELOG
- commit message ให้ระบุผู้แก้ เช่น `Mini v0.4.2: … (ChatGPT)`

**ถ้า ChatGPT push เองไม่ได้:** ให้ ChatGPT ส่ง (1) ไฟล์เต็มที่แก้ หรือ diff (2) ข้อความ CHANGELOG ที่จะเพิ่ม → ผู้ใช้ส่งต่อให้ Claude หรือ commit เอง ห้ามลืมข้อ (2)

**ถ้าแก้ชนกัน:** ยึดโค้ดใน `main` เป็นหลัก แล้วรวมการแก้ของตัวเองทับลงไป อย่าย้อนของอีกฝั่งโดยไม่ได้ถามผู้ใช้

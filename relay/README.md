# 👥 OI Gold Pro relay (ส่งไม้ Binance + Bitget จากเครื่องที่บ้าน)

Binance กับ Bitget บล็อกเซิร์ฟเวอร์ (Cloudflare) ทำให้แถบรายย่อยมีไม้แค่ Bybit
เครื่องที่บ้านดึงได้ปกติ → รันสคริปต์นี้ทิ้งไว้ เซิร์ฟเวอร์จะได้ไม้ครบ 3 ตลาด

- ไม่ต้องใช้รหัส/คีย์ · ไม่แตะบัญชีเทรด · ส่งเฉพาะข้อมูลการซื้อขายสาธารณะ (ราคา ขนาด ฝั่ง)
- หลายเครื่องรันพร้อมกันได้ (เซิร์ฟเวอร์กันนับซ้ำด้วย id ไม้) · มือถือที่เปิด 🐋 ก็ช่วยส่ง Binance เหมือนกัน

## Windows
1. ติดตั้ง Node.js LTS จาก https://nodejs.org (กด Next จนจบ)
2. ดาวน์โหลด `rt-relay.mjs` และ `start-relay.bat` ไว้โฟลเดอร์เดียวกัน
3. ดับเบิลคลิก `start-relay.bat` → หน้าต่างดำขึ้น บอก "ส่ง … รับ …" ทุก 1 นาที = ทำงาน
4. ให้เปิดเองตอนเปิดเครื่อง: กด Win+R พิมพ์ `shell:startup` → วาง shortcut ของ `start-relay.bat` ในโฟลเดอร์นั้น
5. ตั้ง Power Options ไม่ให้เครื่องหลับ (Sleep = Never)

## Mac / Linux / Raspberry Pi
```
node rt-relay.mjs
```
รันค้างไว้ (เช่นใน `tmux` หรือ `pm2 start rt-relay.mjs`)
